## Suspected bugs

- **discriminated-union-non-object-location** (860 disagreements): For an input that is not an object, Zorg reports invalid_union at /kind, a location the document does not have. Zod reports invalid_type at the root. Repro: Z.DiscriminatedUnion("kind", A, B).SafeParse("null") returns invalid_union at /kind. Expected invalid_type at the root, as for any non-object.
- **openapi-30-not-detected** (204 disagreements): The docs say an OpenAPI 3.0 document is refused with unsupported_dialect. The document Zod writes for target openapi-3.0 has no $schema, so nothing identifies it, and it is imported as Draft 2020-12. Repro: Z.FromJsonSchema("{\"type\":\"string\",\"nullable\":true}") imports without error and SafeParse("null") fails. In OpenAPI 3.0, null is allowed.
- **openapi-30-nullable-ignored** (7 disagreements): Because the OpenAPI 3.0 document is read as Draft 2020-12, nullable: true is an unknown keyword that is kept but not honoured, so null is rejected where Zod, and OpenAPI, accept it. Same cause as openapi-30-not-detected. Repro: Z.FromJsonSchema("{\"type\":\"string\",\"nullable\":true}").SafeParse("null").IsSuccess is false. OpenAPI 3.0 says it should pass.

## Not compared

- Zod features with no Zorg counterpart: `transform`, `pipe`, `preprocess`, codecs, `brand`, `z.date`, `z.bigint`, `z.map`, `z.set`, `z.undefined`, `z.custom`, async refinements, and `.catch()`.
- Documents JSON cannot hold: `undefined`, `NaN`, `-Infinity` and `Infinity` (the text `1e400` is the nearest thing). An absent top-level value is not representable either.
- Zorg's output direction (`Direction = Output`): `z.fromJSONSchema` is an input reader, so only the input document is read by Zod.
- Draft-04 and OpenAPI 3.0 as a target of Zorg's emitter: Zod's reader takes Draft 2020-12 and Draft-07. Zorg emits no Draft-04.
- Targets other than the four requested: Zod 4.6.7 also takes `openapi-3.1`, `draft-2019-09` and `draft-06`, and writes a document without `$schema` for each. Zorg's `OpenApi30` and `OpenApi31` emitter profiles are not compared with Zod either.
- Messages. Only issue codes and paths are compared, not text.
- Refinement exceptions: the catalogue's refinements do not throw.
